# EKF / IMM 调参手册

一句话：**哪个参数管什么、调大调小会怎样、遇到什么问题调哪个。**

---

## 0. 先分清三类参数

| 类别 | 有哪些 | 能不能按模型单独设 |
|---|---|---|
| **模型专属** | `sa2`、`v2`、`ca`、`damping`、`ACC_DAMPING`、`DAMPING_TAU` | **必须每个模型一套**，这就是 IMM 的“假设” |
| **IMM 层** | `Pi_`、初始 `mu_`、`mu` 下限 | 三个模型共用一套规则 |
| **全体共享** | `R`、`P0`、`huber_k`、`window_seconds`、`nis_threshold` | **三个模型必须完全一样** |

**为什么 `R` 不能按模型调**：三个模型看的是同一批观测，`R` 描述的是“PnP 有多不准”，跟目标怎么运动无关。如果给某个模型更小的 `R`，它的似然会被人为抬高，什么都不用做就能赢，`mu` 就失去意义了。

---

## 1. 模型专属参数

位置：`tasks/auto_aim/target.cpp` 顶部的 `MOTION_MODELS`。

### `sa2` —— 平移的“不守规矩程度”

| 模型 | 当前值 | 含义 |
|---|---|---|
| M1 匀速 | 10 | 每帧加速度增量的方差 |
| M2 匀加速 | 10 | 同上，但加速度会累积 |
| M3 静止 | 0.1 | 几乎不动 |

- **调大**：跟踪更快，急变向不滞后，但稳态更抖。
- **调小**：更平滑，但急停急起时慢半拍。
- 100 Hz 下，M1 的 `sa2=10` 约等于“速度每帧抖 0.03 m/s”。

### `v2` —— 角速度的“不守规矩程度”

| 模型 | 当前值 |
|---|---|
| M1 | 150 |
| M2 | 400 |
| M3 | 150 |

- **调大**：`w` 响应快，小陀螺跟得上，但 `w` 抖。
- **调小**：`w` 稳，但起转时滞后。
- 建议范围 **100 ~ 600**。超过 600 会明显拖累远距离场景。

### `ca` / `damping` —— 模型的身份

| 模型 | `ca` | `damping` | 效果 |
|---|---|---|---|
| M1 | false | false | 加速度每帧清零 = **匀速模型** |
| M2 | true | false | 加速度延续 = **匀加速模型** |
| M3 | false | true | 平移速度衰减 = **静止模型** |

**这两个一般不要动**，改了就不是原来的模型了。

### `ACC_DAMPING` —— M2 加速度的衰减

当前 **0.90**，位置：`Target::predict` 里。

- **调大**（接近 1）：加速度可以无限漂移，机动响应猛，但远距离会把位置和 `yaw` 一起带抖。
- **调小**（如 0.85）：加速度更“听话”，稳态稳，但急变向时慢。
- 建议范围 **0.85 ~ 0.95**。

### `DAMPING_TAU` —— M3 静止的时间常数

当前 **0.30 秒**。

- **调大**：M3 更像 M1，静止判定更软。
- **调小**：静止判定更硬，但会拖累平移跟踪。
- 建议范围 **0.2 ~ 0.5 秒**。

## 2. IMM 层参数

位置：`Target::init_models()`。

### `Pi_` 对角 —— 模型切换速度

当前 **0.90**。

- 平均驻留时间 = `1 / (1 - 0.90)` = 10 帧 = **0.1 秒**。
- **调大**（0.95）：模型切换慢，`mu` 平滑，但目标真变了要 0.2 秒才反应过来。
- **调小**（0.85）：切换快，响应好，但 `mu` 会一直抖。
- 建议范围 **0.85 ~ 0.95**。

### `Pi_` 非对角

当前 **0.05**。

必须满足：`非对角 = (1 - 对角) / 2`。改对角就要同步改它，否则概率不守恒。

### 初始 `mu_`

当前 `{0.8, 0.15, 0.05}`。

- 只影响开头一两秒。让 M1（匀速）先主导，避免一开始就乱切。
- 一般不用动。

### `mu` 下限

当前 **1e-3**。

- 防止某个模型被压到 0 后再也回不来。
- **调大**：冷门模型复活快，但会污染输出。
- **调小**：低于 1e-4 容易永久锁死。
- 建议范围 **1e-3 ~ 1e-2**。

## 3. 共享参数（三个模型必须一样）

### `R` —— 观测有多不准

位置：`Target::measurement_noise()`。

| 分量 | 当前值 | 折算 |
|---|---|---|
| yaw | 4e-3 | σ ≈ 3.6° |
| pitch | 4e-3 | σ ≈ 3.6° |
| distance | `log(|Δangle|+1) + 1`，最小 1.0 | σ 最小 **1 米** |
| armor_yaw | `log(d+1)/200 + 9e-2` | σ ≈ 17° |

- **调大**：更信运动模型，平滑但滞后；`NIS` 变小，卡方检验失效。
- **调小**：更信观测，跟得快但抖；`NIS` 变大。
- **判断标准**：跑 `ekf_bench`，看 `nis/dof` 是否在 **0.8 ~ 1.2**。当前只有 0.03~0.7，说明 `R` 偏大。
- **这是最该先调的参数**，它同时影响收敛速度、Huber 触发、IMM 的模型辨识。

### `P0_dig` —— 初始有多没底

位置：`tracker.cpp::set_target`，顺序 `x vx y vy z vz a w r l h ax ay az`。

当前：

```
{1, 64, 1, 64, 1, 64, 0.4, 100, 1, 1, 1, 25, 25, 25}
```

- **调大**：开头几帧收敛快，但抖。
- **调小**：开头保守，收敛慢。
- 只影响前几帧，之后会被观测拉平，不用精调。
- 唯一值得改的是 `r/l/h`（当前 1，即 σ=1 米，但真实半径只有 0.2 米）。

### `huber_k` —— 离群点降权阈值

当前 **-1**（自动 = `sqrt(chi2_quantile_95(4))` ≈ **3.08**）。

- **调大**：更信观测，离群点影响大。
- **调小**：更保守，正常观测也会被降权。
- 建议范围 **2.5 ~ 3.5**。

### `window_seconds` / `min_window_samples`

当前 **1.0 秒 / 20 个样本**。

- 控制“连续失败多久算失配”。
- **调大**：判 lost 更迟钝；**调小**：更快判 lost。

### `nis_threshold`

当前 **-1**（自动 95% 分位）。一般不用动。

### Tracker 的 `0.4`

位置：`tracker.cpp`。窗口内失败率超过 40% 判 lost。

- **调大**：更宽容；**调小**：更容易丢目标。

## 4. 遇到什么调什么

| 现象 | 先查 | 再调 |
|---|---|---|
| 急停急起跟不上 | `pred_pos` 是否明显大于 `pos_rmse` | M2 的 `sa2` 调大；`Pi_` 对角调小 |
| 匀速时位置/角度抖 | `pos_rmse` 是否小于基线 | M1 的 `sa2` 调小；`Pi_` 对角调大 |
| 小陀螺 `w` 追不上 | `w_rmse` | M1 的 `v2` 调大；`Pi_` 对角调小 |
| 远距离抖 | `far_noisy` 的 `pos_rmse` | 先修 `R` 的 distance；再调小 M2 `sa2` / 调大 `ACC_DAMPING` |
| `mu` 一直不变（0.8/0.15/0.05） | `nis/dof` 是否远小于 1 | 修 `R`，这是根因 |
| 频繁 lost | `nis_fail_rate` | 若 > 0.4 说明模型真失配，修 `R`/`Q`；否则调大 Tracker 的 0.4 或 `window_seconds` |
| 单帧被错误识别带偏 | `huber_weight` 是否接近 1 | `huber_k` 调小（更早降权） |
| 半径 `r` 估到离谱值 | `diverged` 日志 | 收紧 `P0_dig` 里 `r` 的方差 |
| 小陀螺时 `w` 被压到 0 | M3 是否阻尼了角速度 | 检查 `F(7,7)` 必须为 1，不能被 `damping` 影响 |

---

## 5. 调参顺序

1. **先修 `R`**：把 `nis/dof` 拉到 0.8~1.2。这一步不做，后面都是白调。
2. **再调 `Q`**：三个模型各自调 `sa2` / `v2`，一次只改一个。
3. **最后调 `Pi_`**：控制切换速度，不影响单模型精度。
4. **每次只改一个参数**，跑全部 6 个场景，看综合分和逐场景变化。

命令：

```bash
./cmake-build-debug/benchmarks/ekf/ekf_bench run --out logs/ekf_bench/cur
# 改参数、重编译
cmake --build cmake-build-debug --target ekf_bench -j8
./cmake-build-debug/benchmarks/ekf/ekf_bench run --out logs/ekf_bench/try
./cmake-build-debug/benchmarks/ekf/ekf_bench compare --a cur --b try
```

---

## 6. 不要动

- **加速度必须在状态末尾**（11/12/13）。`aimer`、`planner`、`shooter` 都依赖 0~10 的索引。
- **`Pi_` 的列和必须为 1**。
- **`R` 不能按模型单独设**。
- **`huber_block_size` 必须是 4**，和 4 维量测绑定。
- **M3 不能阻尼角速度**，否则小陀螺的 `w_rmse` 会翻几倍。
